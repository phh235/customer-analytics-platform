# Customer Analytics HTML Slides

## Chạy trên web

Từ thư mục repository:

```bash
cd slides/customer-analytics
python -m http.server 4173
```

Mở `http://localhost:4173`.

## Điều khiển

- Mũi tên trái/phải hoặc lên/xuống: chuyển slide.
- `Space`: slide tiếp theo.
- `F`: bật/tắt toàn màn hình.
- Nút máy in: mở hộp thoại in để xuất PDF.

## Xuất PDF

1. Mở slide bằng Chrome hoặc Edge.
2. Bấm nút máy in ở góc phải.
3. Chọn **Save as PDF**.
4. Chọn **Layout: Landscape**.
5. Chọn **Margins: None**.
6. Bật **Background graphics**.
